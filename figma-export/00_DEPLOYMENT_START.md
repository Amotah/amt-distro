### Phase 2: Server (15 min) 🚀

**What:** Deploy frontend to Vercel

**How:**
```
1. Go to: vercel.com
2. Import GitHub repo: https://github.com/Amotah/amt-distro
3. Root: figma-export

   - VITE_SUPABASE_ANON_KEY

6. Wait 3-5 min
7. Done ✓
```

**Verify:**
```bash
curl -I https://vercel-provided-url
-- Expected: 200 OK
```

### Phase 3: DNS (10 min) 🌐

**What:** Point gwmusic.com.ng to Vercel

**How:**
```
1. In Vercel: Add domain: gwmusic.com.ng
2. Copy nameservers from Vercel
3. Go to domain registrar
4. Update nameservers
5. Wait 15-30 min for propagation
6. Check Vercel → "Valid" status
7. Done ✓
```

**Verify:**
```bash
curl -I https://gwmusic.com.ng
-- Expected: 200 OK
```
